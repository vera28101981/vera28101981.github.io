Как SEO Keyword Collector обрабатывает данные при работе с Google Ads API.

Обновлено 13 октября 2026 · Updated October 13, 2026

Русская версия

Назначение и оператор

SEO Keyword Collector — частная локальная SEO-утилита. Оператором данных является владелец приложения. Публичные вопросы можно задать через GitHub Issues, не публикуя персональные данные. Конфиденциальные вопросы об обработке данных направляются на email поддержки, указанный в окне согласия Google OAuth.

Используемые данные

После разрешения владельца приложение может получать идентификаторы подключённого Google Ads-аккаунта и агрегированные исторические данные Keyword Planner: средние и помесячные объёмы поиска, конкуренцию и другую доступную статистику. Списки ключей, регионы и языки задаёт владелец.

Цели, передача и хранение

Данные используются для SEO-анализа и создания локальных отчётов. Программа передаёт ключевые слова и параметры таргетинга в Google Ads API, чтобы получить статистику. Настройки OAuth, токены доступа и результаты хранятся локально на устройстве владельца; результаты можно экспортировать в CSV. Сайт не собирает эти данные и не продаёт их.

Контроль и удаление

Владелец может удалить локальные файлы и базу данных и отозвать доступ Google в настройках своего Google-аккаунта. Этот статический сайт не содержит форм авторизации, рекламных пикселей или аналитических скриптов. GitHub Pages может вести технические журналы посещений согласно собственной политике конфиденциальности.

Правила Google

Использование данных Google ограничено описанными функциями и регулируется Google API Services User Data Policy.

English version — Privacy Policy

Operator and contact. SEO Keyword Collector is a privately operated local SEO utility. The app owner operates the data. Public questions can be sent through GitHub Issues without posting private information. For confidential questions, use the support email shown on the Google OAuth consent screen.

Data accessed. With the app owner's permission, the utility may access Google Ads customer identifiers and aggregated Keyword Planner historical metrics, including average and monthly search volumes and competition indicators. The owner supplies keywords, regions and languages.

Purpose, processing and storage. The utility submits keywords and targeting settings to the Google Ads API for SEO research, and stores OAuth credentials, results and exports locally on the owner's device. This informational website does not collect OAuth tokens, account credentials, or submitted keywords and does not sell user information.

Control and deletion. The owner can delete locally stored files and revoke Google access through Google account security settings. This website has no sign-in forms or tracking scripts. GitHub Pages may keep technical access logs under its own privacy policy.

Google data policy. Google data is used only for the described features in accordance with the Google API Services User Data Policy.
