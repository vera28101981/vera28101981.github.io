SEO Keyword Collector — Privacy Policy

This policy explains exactly what Google user data this personal desktop SEO application is designed to access, why, how it is processed, where it is stored and how it can be deleted.

Last updated: 14 October 2026

Summary.

SEO Keyword Collector is a personal, non-commercial desktop tool for historical search-volume research. The public website does not offer a login or upload form. When the desktop application is connected with Google OAuth, it is intended to use only the Google Ads account and Keyword Planner data needed for keyword analysis. Project data stays locally on the user's device. No Google user data is sold or used for AI training.

1. Operator, service and contact

Application name: SEO Keyword Collector. It is independently operated as a personal, non-commercial software project and is not affiliated with or endorsed by Google LLC. The application is being configured and is not currently a publicly hosted service. This website provides a public description of its intended functions and data practices.

To ask general questions or request information about this policy, contact the project owner through the project's GitHub Issues page, or the developer support address shown on the Google OAuth consent screen. GitHub issues are public: never post passwords, access tokens, private business information or other sensitive data.

2. Which data may be accessed

Google data is accessed only after the owner has provided authorization through Google OAuth for an account they are permitted to use. The application's intended scope is https://www.googleapis.com/auth/adwords (Google Ads API). The scope itself can permit more than the read operations this application intends to perform.

The app does not request access to Gmail messages, Google Drive files, Google Contacts, calendars, browser history or private Search Console properties. The intended API calls are for historical keyword planning statistics, not to create ads, edit campaigns or change budgets.

3. How and why the data is used

  1. The user imports or enters their own list of keyword phrases, and chooses a project, target geography and language.
  2. The user explicitly authorizes their Google Ads account through Google's OAuth interface.
  3. The tool uses the authorized account and the supplied keyword/targeting settings to request aggregate historical keyword metrics from Google Ads API.
  4. The tool associates returned statistics with the original keyword/project and provides local analysis or CSV export.

Google user data is used solely to provide the keyword-research functionality described above. It is not used to profile individual users, target advertisements, send marketing messages, train general-purpose AI models or create synthetic media. The tool does not generate or alter intimate images.

4. Sharing and third parties

The tool is designed to communicate with Google Ads API over HTTPS to retrieve the user's requested statistics. User-provided keywords, selected locations and language settings are sent to Google as part of these API requests. Historical metrics are returned by Google to the authorized user's device.

No separate hosted SEO Keyword Collector backend is used. The project operator does not sell, rent, or transfer Google user data to advertising networks, data brokers or unrelated third parties. Exported CSV reports remain under the user's control; if the user manually shares them, that sharing is their own decision.

The public information website is hosted on GitHub Pages. It has no login or data upload forms, and its source contains no analytics pixels or tracking scripts. GitHub may process technical web access logs under GitHub's privacy terms; the website operator does not receive Google Ads OAuth credentials through these public pages.

5. Local storage and security

The desktop application is designed to keep keyword lists, project configuration and returned metrics locally, including a SQLite database and CSV files on the user's device. OAuth settings or refresh tokens, if retained to allow future requests, are also local to the user's environment. They are not intended to be published to GitHub or written into site HTML.

The user's device and file permissions protect locally saved files. Users should not publish OAuth credentials or share them with other people. API requests use HTTPS. Because the tool is still under development, these statements describe the intended processing model; the implemented tool must be kept consistent with this policy before real account data is used.

6. Retention, control and deletion

Keyword lists, historical metrics, exported CSV reports and local project settings are retained on the user's device until the user deletes them. No independent server-side archive is operated by SEO Keyword Collector. To remove data, the user can delete the relevant local CSV files, project database and configuration/credential files from their computer.

Google access can be withdrawn through Google Account → Third-party connections. Revocation prevents further authorized API requests until the user grants access again, but it does not automatically delete any local CSV reports or database files. Those need to be removed separately.

7. Data minimization, limited use and changes

Only Google Ads data necessary to support the described keyword-research features is intended to be requested and used. The project will not request permissions for unrelated Google services. Use and transfer of information from Google APIs must comply with the Google API Services User Data Policy, including the Limited Use requirements where applicable.

If the tool's collection, storage, sharing or use of Google data changes, this privacy policy must be updated before the new use is introduced, and users must be informed and asked for any required consent. This policy should remain consistent with both the application and its OAuth consent screen.

8. Privacy contact and website access

Privacy questions may be submitted via the project's GitHub contact page without including sensitive details, or by using the support email listed in the OAuth consent screen. This Privacy Policy, the homepage, and Terms of Use are available to everyone without signing in.

Кратко по-русски

SEO Keyword Collector — личная некоммерческая программа для анализа исторической частотности через Google Ads API. После согласия владельца через Google OAuth программа получает доступ к выбранному Google Ads-аккаунту (идентификатору клиента) и агрегированной статистике Keyword Planner: средней и помесячной частотности, конкуренции и другим доступным метрикам.

Ключевые слова, регион и язык задаёт сам пользователь. Для запроса статистики они передаются в Google Ads API. Результаты и настройки планируется хранить локально на компьютере, а не на сервере проекта. Данные не продаются, не используются для рекламы и обучения ИИ. Доступ можно отозвать в настройках аккаунта Google; локальные CSV, базу данных и файлы учётных данных пользователь удаляет самостоятельно.

Этот сайт не требует авторизации. Для обращений используй GitHub Issues без передачи личных данных либо email поддержки, указанный на экране Google OAuth.
