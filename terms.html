SEO Keyword Collector — Terms of Use

Rules for intended personal use of SEO Keyword Collector, an independent desktop utility for historical keyword search statistics.

Last updated: 14 October 2026

1. Purpose

SEO Keyword Collector is an independent, personal, non-commercial desktop software project under development. Its intended function is retrieving aggregated historical keyword-planning estimates from Google Ads API for SEO research, grouping results by personal project/website and geography, and making CSV reports on the user's own device. It is not a Google product, online advertising platform or public account service.

2. Authorization

Use of the Google Ads API requires the owner's own authorized Google Ads account, OAuth consent and appropriate API permissions. Users must comply with Google API Terms of Service and Google Ads API conditions and may connect only accounts they are permitted to access. The tool is designed for historical metrics retrieval, not campaign creation or ad spending.

3. Data use

Information access, use, storage, sharing, retention and deletion are detailed in the SEO Keyword Collector Privacy Policy. Google user data is intended only for the described functions; no user data is sold or used for advertising profiles or AI training.

4. No image generation or unrelated use

The project is an SEO analytics utility, not a generative AI system. It does not create, change or distribute images, video or intimate content. It does not use Google APIs for unrelated purposes.

5. Availability and accuracy

Google Keyword Planner metrics are estimates, not guaranteed exact search counts; Google may consolidate close keyword variants. Data availability varies by account, location and language. The project is being configured and live Google Ads API access remains subject to Google approval, quotas and service availability. No guarantee of uninterrupted access or absolute data accuracy is made.

6. Support and privacy

This website is informational and accessible without signing in. General questions can be sent through project GitHub Issues. Never publish OAuth tokens or personal data in public issues. The developer contact email is available on the Google OAuth consent screen.

Условия использования на русском

SEO Keyword Collector — личная некоммерческая программа, находящаяся в разработке. Она предназначена для анализа исторической частотности ключей через Google Ads API с авторизацией Google OAuth, выбора регионов и экспорта результатов в локальные CSV-файлы.

Программа не размещает рекламу и не изменяет рекламные кампании. Значения частотности являются оценочными; доступность информации и самого API зависит от Google. Подробное описание обработки данных — в политике конфиденциальности.
