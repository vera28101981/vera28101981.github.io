Назначение и ограничения SEO Keyword Collector.

Обновлено 13 октября 2026 · Updated October 13, 2026

Русская версия

Назначение. SEO Keyword Collector — частная утилита для получения исторической агрегированной статистики поисковых запросов с помощью Google Ads API. Доступ предоставляется владельцу и его явно уполномоченным пользователям.

Использование. Необходимо соблюдать условия Google Ads API и обеспечивать законный доступ к используемым аккаунтам.

Ограничения. Метрики Keyword Planner являются оценками; Google может объединять близкие варианты запросов, а статистика для отдельных регионов и языков может быть недоступна. Результаты не являются данными Яндекс Wordstat. Работоспособность зависит от квот и разрешений Google Ads API.

Ответственность. Оператор не гарантирует непрерывную работу приложения или абсолютную точность статистики. Это независимый проект, не поддерживаемый и не одобренный Google LLC.

Связь. Публичные вопросы: GitHub Issues. Не передавайте туда личную информацию.

English version — Terms of Use

Service. SEO Keyword Collector is a privately operated keyword research utility for using aggregated historical Google Ads API metrics in SEO workflows.

Acceptable use. Users must comply with Google Ads API terms and applicable law, and must only access accounts for which they have authorization.

Limitations. Keyword Planner values are estimates and may combine close variants or be unavailable in some regions and languages. The tool's availability depends on Google API permissions and quotas. No guarantee is made of uninterrupted functionality or metric accuracy.

Independence. The tool is not an official Google product, and is not affiliated with or endorsed by Google LLC.

Contact. Public questions: GitHub Issues (please do not disclose personal data).
