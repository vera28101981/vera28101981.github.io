SEO Keyword Collector

SEO Keyword Collector is a desktop application for SEO keyword research. It uses the Google Ads API (Keyword Planner) to get historical search volume for a list of keywords, so the user can see how often people search for each keyword in a selected country, region, city and language.

The app only reads keyword statistics. It never creates or changes ads, campaigns or budgets, and it never spends money.

What SEO Keyword Collector does

The purpose of SEO Keyword Collector is to help with SEO planning: choosing which keywords to target on a website, based on how often people search for them. The app has three functions:

Get keyword search volume

For each keyword, the app gets average monthly searches and month-by-month search volume from Google Keyword Planner through the Google Ads API.

Compare locations and languages

The same keywords can be checked for different countries, regions, cities and languages, for example to compare demand in two cities.

Save and export reports

Results are grouped by SEO project, saved on the user's computer and can be exported to a CSV file for analysis in a spreadsheet.

How it works

  1. Load keywordsThe user opens a CSV file with keywords in the app on their computer.
  2. Choose settingsThe user selects their Google Ads account, the location and the language.
  3. Sign in with GoogleThe user gives consent on the Google OAuth screen. The app then requests keyword statistics from the Google Ads API.
  4. Review resultsThe app shows the statistics and saves them on the user's computer as a local database and CSV file.

Sign-in with Google happens only inside the desktop app. This website has no sign-in and never asks for Google credentials.

How SEO Keyword Collector uses Google user data

The app requests one OAuth scope: https://www.googleapis.com/auth/adwords. This is the only scope that the Google Ads API offers, and it is required to use Keyword Planner. With the user's consent, the app accesses only:

  • the IDs of the Google Ads accounts the user can access, so the user can choose which account to use for requests;
  • historical keyword metrics from Keyword Planner (average monthly searches, monthly search volumes, competition and bid estimates) for the keywords the user entered.

This data is used only to show and save keyword statistics for the user. It is stored only on the user's computer and is not sent to the developer or to any third party. It is not used for advertising, not sold, and not used to train AI or machine-learning models. The app does not request access to Gmail, Google Drive, Contacts, Calendar or any other Google service.

Full details are in the SEO Keyword Collector Privacy Policy.
