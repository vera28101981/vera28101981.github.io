SEO Keyword Collector

SEO Keyword Collector is a personal, non-commercial desktop utility being developed to analyze historical keyword search volume through the Google Ads API (Keyword Planner). Its purpose is SEO research across different websites, countries, cities and languages.

Historical keyword metrics Country and city targeting Local CSV reports

This is the publicly accessible homepage for the OAuth application “SEO Keyword Collector.”

No account, login or registration is required to view this page, the Privacy Policy or the Terms of Use. The desktop program is being configured and is not offered as a public hosted service.

What the application does

Research search demand

Request Google Keyword Planner historical metrics including estimated average monthly searches and monthly trend data for keyword lists.

Choose locations and language

Analyze the same keywords for a selected city, region, country and language. Each request uses its own targeting settings.

Organize local reports

Associate keywords with personal SEO projects, preserve earlier results and export the findings to CSV for manual analysis.

How it works — intended workflow

  1. Import keywordsThe user opens their own CSV keyword file in the local program.
  2. Set targetingThe user selects an authorized Google Ads account, geography and language.
  3. Authorize and requestWith the user's OAuth consent, the app queries the Google Ads API for historical keyword metrics.
  4. Review locallyThe results can be stored in a local project database and exported as a CSV report.

Google Ads access is needed only when the owner connects the desktop tool. No Google authorization takes place on this website, and this site does not collect credentials or offer a sign-in page. Features are subject to Google Ads API approval and regional data availability.

Why Google account access is requested

The Google Ads API requires OAuth permission to work with an account the user is authorized to access. The intended application uses https://www.googleapis.com/auth/adwords to identify the selected Google Ads customer and request aggregated historical Keyword Planner metrics. That scope may allow broader Google Ads actions, but the utility is designed for keyword research, not for changing campaigns, placing ads, or spending money.

It does not request Gmail, Google Drive, Google Contacts or other unrelated Google account information. Google user data is not used for advertising profiles, sale to data brokers or training AI models.

For full details about access, use, storage, sharing, retention and deletion, read our Privacy Policy.

What it is not

SEO Keyword Collector is not a Google product and does not provide Google's search engine itself. It is not a generative-AI or image-creation application; it does not generate images or videos, including non-consensual intimate imagery. It only supports SEO keyword analysis using aggregated search statistics.

Google's keyword metrics are estimates: similar queries may be grouped and results can differ by location and language. The tool is under development, and access is not yet guaranteed.
