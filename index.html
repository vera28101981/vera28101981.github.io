SEO Keyword Collector

SEO Keyword Collector is a private desktop application for collecting historical keyword search metrics via the official Google Ads API (Keyword Planner). It helps SEO specialists analyze keyword lists across multiple websites, countries, regions and languages.

Keyword search volume · Historical monthly trends · Geo targeting · CSV export

Public information website — no sign-in required. The application is currently being configured. This website explains the app's purpose, data access and privacy practices. It does not accept Google credentials, Google OAuth tokens, or keyword uploads.

What does the application do?

  1. The owner imports a CSV file with SEO keywords for a website or project.
  2. The owner selects a Google Ads account they are authorized to use, and selects a country, city/region and language.
  3. After the owner's Google OAuth authorization, the desktop utility requests historical search-volume metrics using KeywordPlanIdeaService.GenerateKeywordHistoricalMetrics.
  4. The utility stores results locally and exports CSV reports for SEO planning. Queries can be repeated later to compare historical trends.

Google can group close keyword variants and return estimates rather than exact query counts. Availability varies by account, country and language. The application does not access Google Search Console, Gmail, Google Drive, or unrelated account data.

Keyword analysis

Average monthly searches, monthly history and available advertising competition metrics.

Multiple SEO websites

Separate keyword lists for each site with independently selected locations and languages.

Local-first processing

CSV input/output and a local database; no hosted dashboard or online collection of credentials.

How the application uses Google data

The app requires the owner's explicit OAuth permission to access the Google Ads API. It will access authorized Google Ads customer identifiers and aggregated keyword-planning metrics to produce SEO reports. It does not publish account data, sell or share Google user data with advertisers, or use it to train AI models.

It is not an AI image generator: the tool does not create, alter or distribute images or videos, including intimate imagery, or use Google APIs for such purposes. It only processes keyword planning statistics.

Learn more in the Privacy Policy and Terms of Use. There is no login required to access any of these public pages.
