Keyword research & historical metrics

Сбор частотности поисковых запросов по странам и регионам

SEO Keyword Collector — локальная утилита для исследования агрегированной статистики ключевых слов через Google Ads API. Предназначена для обработки семантики нескольких SEO-проектов.

Статус проекта: настройка подключения Google Ads API продолжается. Этот сайт только информирует о проекте; здесь нет входа в Google или сбора паролей и токенов.

Массовая обработка

Импорт ключевых фраз из CSV, разбивка на пакеты, экспорт результатов.

Страны и языки

Исторические показатели по выбранным географическим областям и языкам, если их предоставляет Google Ads API.

Локальное хранение

Сохранение истории и результатов в SQLite и CSV на компьютере владельца.

Как используются данные Google

После отдельной авторизации владельца программа сможет запрашивать агрегированные показатели Google Keyword Planner: средние и помесячные объёмы поиска, а также показатели конкуренции. В Google отправляются выбранные ключевые слова и параметры региона/языка.

OAuth используется только для доступа к Google Ads API с разрешения владельца. Сайт не обрабатывает авторизацию, не собирает ключевые слова и не принимает OAuth-токены.

About this project

SEO Keyword Collector is a privately operated desktop utility for querying aggregated historical keyword metrics using the Google Ads API. It can organize lists of keywords by website, language and geographical area, and store results locally.

This public website is informational only, and does not request Google passwords, tokens, or user data. Read our Privacy Policy and Terms of Use.
